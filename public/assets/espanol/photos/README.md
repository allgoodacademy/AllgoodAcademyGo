# Español photos

William's real travel photos for the Español hub and stories.

- One folder per story: `el-mundial/`, `el-viaje/`, `hub/`.
- Photos show places and William. No other identifiable faces unless that person agreed.
- Prepared in chat before they land here: resized to 1600px on the long side, WebP, location (GPS) and camera data removed.
- Names are lowercase with dashes, e.g. `el-mundial/saransk-stadium.webp`. A changed photo gets a new name (`-v2`), because /assets/ is cached for up to a year.
