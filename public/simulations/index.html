How it works in class

  1. 1

    Project it

    Press Present. The text gets big enough for the back row, and every choice gets a letter, A to D.

  2. 2

    Everyone guesses

    Students write a guess, then vote with their fingers. You lock in the class answer before anyone sees the result.

  3. 3

    Test it together

    Run the simulation and watch what happens. Jodi explains why, especially when the class guessed something else.
