How to play

Messages fall from Scam HQ toward your friends. Tap one and time stops so you can read it.

Let it in if it’s real: new friends join your crew. If it was bait, hooks pull friends away.

Block it if it’s bait, then name the trick. Name it right for bonus friends. Block a real one and those friends never come.

A message you never tap lands as if you let it in. When the messages stop, your crew charges Scam HQ. More friends than guards and you win.
